Privacy Policy

Last updated: November 2026

Content Studio is a personal tool used only by its developer to manage the developer's own YouTube channels. It is not a service for the public and does not collect information from any other users.

Data accessed

With the developer's explicit authorization through Google OAuth, the app uses the YouTube Data API and YouTube Analytics API to (a) upload videos to the developer's own channels and (b) read aggregate performance statistics (such as views and watch time) for those channels.

Data storage and use

OAuth tokens and channel statistics are stored in a private database accessible only to the developer. Data is used only to operate and improve the developer's own channels. It is never sold, shared with or disclosed to third parties, or used for advertising.

Google API Services

Content Studio's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
